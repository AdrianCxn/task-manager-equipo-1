# Sprint 1

## Objetivo

Desarrollar una primera versión funcional del Task Manager que permita crear, visualizar y gestionar el estado de las tareas.

## Historias seleccionadas

- **US01:** Crear una tarea
- **US02:** Mostrar tareas
- **US03:** Completar tarea

## Responsables

| Historia | Responsable | Prioridad |
|---|---|---|
| US01 - Crear una tarea | Ernesto Córdova | Alta |
| US02 - Mostrar tareas | Ernesto Córdova | Media |
| US03 - Completar tarea | Ernesto Córdova | Media |

*(Nota: US04 y US05 permanecen en el Product Backlog / siguientes iteraciones).*

## Criterio de terminado (Definition of Done)

Una historia se considera terminada cuando:

- La funcionalidad está completamente implementada.
- Pasó las pruebas correspondientes (columna TESTING).
- Cumple con sus criterios de aceptación establecidos.
- El código fue enviado al repositorio de GitHub (`task-manager-equipo-1`).
- La tarjeta se movió a la columna **DONE** en el tablero de Jira.
